# Curso Django: Projeto Receitas

Este repositório foi criado exclusivamente para fins de **estudo e aprendizado**. O objetivo principal é praticar o desenvolvimento web utilizando o framework Django, seguindo as aulas do curso da Udemy.

## Finalidade do Projeto
* Praticar os conceitos fundamentais do Django (MVT, ORM, URLs e Views).
* Entender a estrutura de aplicações e organização de código Python.
* Desenvolver um sistema básico de receitas para fins didáticos.
* Ambiente seguro para testes, erros e experimentações de código.

## Tecnologias Utilizadas
* **Python**
* **Django**
* **HTML / CSS**

---
*Nota: Este é um projeto de laboratório e aprendizado, não voltado para produção.*
